# Languages of Hindu Culture — Name in Different Scripts

Open `index.html` in any modern browser. No installation is required.

Enter a name in English and click one of the nine languages to display an approximate phonetic rendering in the selected writing system. No audio features.

**Note:** This is a lightweight, offline transliteration demo, not a translation engine. The names Krishna, Rama, Parthiv, and Swaminarayan have curated spellings. Other names use approximate character rules and may need correction, particularly in Tamil, Bengali, and Sanskrit. For production-quality transliteration, connect a specialized Indic transliteration library or API.
